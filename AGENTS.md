# AGENTS.md

Ledger Forever is a WoW: Forever addon (Interface 16001): one progress book with three daily orders, a stamp per zone whose story the character finished and a cosmetic rank ladder fed by marks. It needs ForeverCore (declared in `## OptionalDeps` so it can load and explain a missing core; the release pinned in `tools/forever-core.txt` ships in the zip). Rewards are cosmetic only and nothing is sent to other players.

## Commands

```sh
python3 tools/doctor.py             # first on a new machine: every tool pin, with a fix for each problem
python3 tools/gate.py               # the fast local gate: format, lint, typecheck, specs, changelog, credits, rules
python3 tools/gate.py --changed     # only the steps the diff against origin/main reaches
python3 tools/phrases.py > Locales/phrases.txt   # after any text change
```

`gate.py` loads ForeverCore from `$FOREVER_CORE`, else `../forever-core`: set it in a worktree. CI runs the same checks
plus the simulator (`tools/forever_sim`), the package build, actionlint, zizmor and gitleaks. A change's player-facing
notes go in `changes/<issue>.md`; only the release commit edits `CHANGELOG.md`
(`python3 tools/changelog.py release X.Y.Z`). Release: `.agents/skills/release/SKILL.md`.

## Layout

- `Core/`: `Core.lua` registers with ForeverCore and owns the one opener (slash, compartment, tracker header);
  `Require.lua` stops the addon with one on-screen line when the loaded core lacks a member this addon calls, never by
  version; `ForeverRequire.lua` is the shared file, copied from ForeverCore; `Secret.lua` has `ns.Readable`/`ns.Usable`.
- `Data/Credits.lua` is generated by `python3 tools/forever_tools/credits.py` from `THIRD_PARTY.md`. A generated data
  file names its generator and sources in its header. `Locales/enUS.lua` is keyed by the English text.
- A new Lua file goes in `LedgerForever.toc` or never runs (Lua 5.1, no `require`).
- `tools/forever_tools/` and `tools/forever_sim/` are vendored: never edit them here, refresh with their `sync.py`.

## Rules

- Player-visible text goes through `L["whole sentence"]`, or a Blizzard GlobalString that says exactly the same.
- Never touch Blizzard's Lua state (WFA-38): no `hooksecurefunc(object, ...)`, replaced method or field written on a
  Blizzard table.
- Never stretch art: draw icons and atlases at native aspect through one art helper; `tools/lint_art.py` refuses a raw
  `SetAtlas`/`SetTexture` elsewhere unless its line says `-- art-ok: reason`.
- The addon prints nothing to chat and sends nothing to other players.
- New host globals go in `.luacheckrc`, with real types in `types/` where upstream lacks them. Never add a LuaLS
  globals allowlist.

## Standards
