# Changelog

What changed in each release, in the terms someone keeping a progress book would notice. Dates are UTC.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the versions follow
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). The entries are prose rather than bare
Added/Fixed lists: what matters about a release is why the book now shows something different.

Each version's entry is also its release notes on GitHub, CurseForge and Wago. API changes other addons' authors need
go under an optional `### For addon authors` subsection after a version's player bullets.
